# Surface: device / phone UI (preview.html) + admin (admin.html) + README assets

Scope: the Neondeck client surfaces. Mode: Operate (the visitor completes a task: glance at session states, focus a session, press an action). Admin is Operate too, used occasionally on desktop.

Audience/job: developers juggling many Claude Code sessions; glance (who needs me) and act (focus, Esc/Enter/Interrupt, custom buttons). Priority signal: sessions waiting for the user. Must not feel like a web app: it is an object on the desk.

Constraints: black ground, offline (no CDN/external fonts), Pi Zero 2 W budget, Italian UI, square tiles, big touch targets, demo regenerated by scripts/build_demo.py.

## Direction contract

THESIS: Neondeck is a night departure board in a neon city: every session is a service on the board, and the ones waiting for you are boarding. It refuses the generic dark dashboard of rounded cards with neon glow.

OWN-WORLD: Matte black ground; every display string drawn in an authored 5x7 dot-matrix LED face (lit dots over a faint unlit dot field); LED amber is reserved for "tocca a te" and nothing else; working/shell/terminal states are low-intensity white LED; magenta neon is the brand and the selection marker only; red/green LEDs only for press results. System sans only for explanatory prose in admin and error screens. Motion is LED switching: steps(), no easing.

STORY: From a metre away the user sees one number, how many sessions need them, and those tiles lit amber; tapping one brings it forward; the action column fires keys into it.

FIRST VIEWPORT: 800x480. Header band 52px: magenta dot-matrix NEONDECK left, monumental amber counter "TOCCA A TE 2" centre, white dot-matrix clock and lamp-dots for terminals right. Left 60%: 4-column square session tiles sorted waiting first; each tile: status word + host code top row, LED-dot mascot centre, dot-matrix project name bottom (marquee-scrolls when too long), age. Right 40%: 3-column action tiles with authored dot-matrix glyph icons. Signature move: waiting tiles' status word blinks at boarding cadence, and a tile whose state changes re-draws with a left-to-right dot wipe.

FORM: departure-board LED dot matrix, candidate 4 of 7 on the ordered list, seed key e00c459a. Raises kept: state encoded by form as well as hue (from emission-line rail); full colour only for who waits for you (from Factory catalog sleeve); monumental single count (from airport wayfinding).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Cited adaptations

- Host code sits at the right end of the session tile's last row (beside the age), not in row 1: "TOCCA A TE" needs about 78% of the tile width to stay unscrolled at the minimum legible cell, so row 1 belongs to the status word alone.
